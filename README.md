# Smart Campus Companion 🎓

Smart Campus Companion is a web-based project developed to make campus-related activities easier to manage. The main idea is to bring useful campus features together in one place through a simple and user-friendly website.

The project includes separate interfaces for users and administrators, along with a backend that handles the application's functionality.

## What does this project include?

- **Login and Registration:** Pages for users to log in and register.
- **Student Interface:** A website interface for accessing campus-related features.
- **Admin Panel:** A separate interface for administrative tasks.
- **Backend:** A Python-based backend that supports the application.
- **Frontend:** Web pages built using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Git and GitHub

## Project Structure

The project is divided into two main folders:

- `smart-campus-frontend` – Contains the website pages and user interface.
- `smart-campus-backend` – Contains the Python backend and related files.
