Smart Campus Companion
All-in-one portal for managing daily campus activities

1. User Authentication

Secure login and registration system for Students, Faculty, and Admins. Passwords are encrypted using industry-grade hashing. Roles determine access to different modules.

2. Lost & Found Management

Students and staff can report lost or found items. Includes image upload, filtering by status (Lost/Found/Returned), and admin oversight.

3. Ground Booking System

Students can view and faculty can request booking of sports grounds. The system checks for time conflicts and supports admin approval or rejection.

4. Auditorium Booking System

Allows departments and clubs to reserve the auditorium for events. Conflict detection ensures fair scheduling and prevents overlapping events.

5. Faculty Availability Checker

Students can check real-time availability status (Available / Busy) of faculty members. Faculty can update their own status.

6. Admin Dashboard

Admins manage users, roles, and booking approvals. Provides an oversight dashboard for all campus operations.

7. Responsive Frontend

Clean UI built using HTML, CSS, and JavaScript. Optimized for desktop and laptop use in campus labs.
